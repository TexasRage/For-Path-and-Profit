Expedition Actions represent the primary activities characters undertake during structured exploration. At the beginning of each [[Quarter-Day]], each character chooses how they will spend their available time.

Unless otherwise specified, an Expedition Action takes one [[Quarter-Day]] to complete. Each action's description explains any special requirements, additional time, or restrictions that apply.

Some actions can be performed by multiple characters simultaneously, allowing the [[Expedition]] to work together on the same task. When an action does not support multiple characters, additional characters may still assist using the **[[Assist Maneuver]]**, provided the action allows assistance.

The available Expedition Actions are:

- [[Explore]]
- [[Scan]]
- [[Forage]]
- [[Hunt]]
- [[Fish]]
- [[Cook]]
- [[Make Camp]]
- [[Modify Equipment]]
- [[Rest]]
- [[Forecast]]
- [[Adventure]]
